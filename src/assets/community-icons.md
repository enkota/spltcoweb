# Community menu icons

Discord, Reddit, and Fandom SVG paths are from Simple Icons (CC0):

- https://github.com/simple-icons/simple-icons/blob/develop/icons/discord.svg
- https://github.com/simple-icons/simple-icons/blob/develop/icons/reddit.svg
- https://github.com/simple-icons/simple-icons/blob/develop/icons/fandom.svg

The X icon reuses the existing website icon. All four SVGs are embedded in the shared header at build time.
